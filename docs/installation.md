# Installation

SDA requires **Python 3.14 or later**. With **Conda** installed, use the commands below
to create a python environment and install SDA with its dependencies.

=== "Linux"

    Open a terminal, then run:

    ```bash
    conda create --name sda python=3.14
    conda activate sda
    python -m pip install "https://github.com/FlavienMattern/sda/archive/refs/heads/main.zip"
    ```

=== "Windows"

    From the Start menu, open **Anaconda Prompt**, then run:

    ```bash
    conda create --name sda python=3.14
    conda activate sda
    python -m pip install "https://github.com/FlavienMattern/sda/archive/refs/heads/main.zip"
    ```
